# 🏝️ 我的学习冒险岛

灵感来自小花生的文章《一个月养出"自律娃"，手搓"亲妈牌"APP让老母亲终于喘口气了》。这是一个给小学生用的游戏化学习计划工具，可以**安装为 PWA**（手机桌面 / 电脑应用），离线也能用。数据只保存在本机浏览器里。

## 功能

| 文章里的痛点 | 应用里的做法 |
| --- | --- |
| 周目标漏做就"欠债"，孩子摆烂 | **滑动窗口周目标**：只显示"本周还差 N 次"，不翻旧账；做满后任务自动消失；作业多时可"跳过今日"（只有后面还来得及才能跳） |
| 打卡非黑即白 | **四档星级**：⭐ 完整高质量 1 星、🌗 尽力没做完 ½ 星、🌓 完成但质量欠佳 ½ 星、❌ 没动手 |
| 看不清全局、不会复盘 | **一周视图** + **自动周报**（完成率、星星分类、学习时长、每项是否达标）+ 三个可编辑栏（做得好 / 需改进 / 下周计划），历史周报可翻看 |
| 学习枯燥 | **冒险岛**：英语=魔法森林、数学=数字城堡、语文=诗词山谷、其他=神秘遗迹；**故事主线**每周解锁一章（绿野仙踪等内置书库，可自定义书目） |
| 奖励没吸引力 | **盲盒**：每天全部完成 +1 抽奖券、击败 BOSS +2；奖品分普通/稀有/传说，概率、颜色可调；抽到的奖品进奖品库，攒够星星再兑换，同价位可调换 |
| 硬骨头任务总逃避 | **BOSS 战**：可标记 BOSS 任务，血条随完成度下降，没做完不能攻击；7 个 BOSS 按星期轮换 |
| 其他 | 能量树（20 片叶子）、计划 vs 实际用时图、学期赛季与称号（冒险新手 → 传说冒险王）、成就徽章、节日限定皮肤（春节/中秋/国庆自动触发）、家长密码、导出/导入备份 |

## 本地运行

```bash
npm start      # http://localhost:5173
npm test       # 运行逻辑单元测试
```

纯 HTML/CSS/JS（ES 模块），无需构建。Service Worker 需要通过 http(s) 访问，直接双击 `index.html` 也能用，但不能离线/安装。

## 部署并安装到手机

1. 仓库 **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**。
2. 推送代码后，`.github/workflows/pages.yml` 会自动测试并发布到 `https://<用户名>.github.io/my-pwa-app/`。
3. 用手机打开该网址：
   - **Android / 电脑 Chrome、Edge**：地址栏或菜单里点「安装应用」。
   - **iPhone / iPad**：用 Safari 打开 → 分享 → 「添加到主屏幕」。

也可以把这些文件放到任何支持 HTTPS 的静态托管（Netlify、Vercel、Cloudflare Pages 等）。

> 更新文件后，把 `sw.js` 里的 `VERSION` 改一下，已安装的应用就会拉取新版本。

## 目录

```
index.html            页面入口
manifest.webmanifest  PWA 清单
sw.js                 Service Worker（离线缓存）
css/style.css         样式与主题
js/app.js             界面与交互
js/logic.js           纯计算逻辑（滑动窗口、星星、BOSS、周报、剧情、徽章）
js/data.js            内置数据（默认任务、书库、BOSS、奖品、节日）
js/store.js           localStorage 存取与备份
tests/                node:test 单元测试
```
