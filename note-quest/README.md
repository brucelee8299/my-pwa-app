# 🎹 识谱小勇士

给学钢琴的孩子（约 8–12 岁）的五线谱识音 PWA。每天 10 分钟，像背单词一样记牢五线谱上的每个音，并把它的**音、形、意**连在一起：

| | 是什么 | App 里怎么练 |
| --- | --- | --- |
| **形** | 音符在谱上的位置：哪个谱表，第几线、第几间，几条加线 | 五线谱上直接画出音符；「摆音符」游戏反过来让孩子自己把音符放到谱上 |
| **音** | 怎么唱、听起来是什么声音：唱名 do re mi、简谱 1 2 3、真实音高 | 每次作答都会播放这个音的钢琴声，按钮上同时写着唱名、音名和简谱 |
| **意** | 钢琴上的哪一个键（要对到正确的八度） | 在屏幕钢琴上按键答题，也可以接电子琴（MIDI）在真琴上按 |

孩子**自己就能判断对错、自己纠正**，家长不需要会识谱：

- 每题自动判断对错。
- 答错时，App 会给出正确的唱名，点亮对应的琴键，播放声音，还会提示怎么从最近的「地标音」数过去（例如「从地标 G（第二线）往下数 2 格：G → F → E」）。
- 孩子必须自己点一次正确答案才能继续，这个音隔 2 题后会再考一次。

## 识谱水平标准（App 按这个自动评级）

| 级别 | 范围 | 要求 |
| --- | --- | --- |
| 🌱 入门 | 中央C 附近：高音 C4–G4、低音 F3–C4（双手五指位置） | 每个音 ≤ 5 秒，正确率 ≥ 90% |
| 🌿 基础 | 五线四间全部：高音 E4–F5、低音 G2–A3 | 每个音 ≤ 3 秒，正确率 ≥ 90% |
| 🌳 熟练 | 加上下加一、二线：C2–C6 共 29 个音，并且在键盘上能找对八度 | 每个音 ≤ 2 秒，正确率 ≥ 95% |
| 🏆 流畅 | 大谱表高低音混合 | 平均 ≤ 1.5 秒，正确率 ≥ 98% |

为什么以 1.5 秒为目标：简单乐曲每秒大约要读 1–2 个音。单个音的辨认降到 1.5 秒以内，识谱就不再拖慢弹琴，孩子可以开始边看边弹。达到「流畅」以后，下一步要靠琴课来学：音程（看两个音之间的距离，不再一个个认）、节奏、升降号和调号。这些不在本 App 的范围内。

评级规则：前面的关卡都要通过，范围内每个音最近至少答过 3 次，总体正确率和中位用时都要达标，而且不能有明显薄弱的音。

## 学习路线：13 关，4 个岛

采用**地标法**：先记住几个「地标」（中央C、高音谱表第二线的 G、低音谱表第四线的 F、两个谱表里的 C、上下加二线的高音 C 和低音 C），其他音都从最近的地标往上或往下数。高音谱表和低音谱表交替学，左右手都不落下。

1. 🏡 **中央C小镇**：C D E（高音）→ F G（G 地标）→ C B A（低音）→ G F（F 地标）
2. 🏝️ **五线谱群岛**：两个谱表的线和间全部学完
3. ⛰️ **加线高山**：上加线、下加线，从低音 C2 到高音 C6
4. 🏰 **大谱表城堡**：高低音混在一起出现（总决战）

每关结束有一个 BOSS：要认对 20 个音，每题限时 6 秒，错 3 个就失败。
- 1 星：错误不超过 2 个
- 2 星：平均用时 ≤ 2.5 秒
- 3 星：全对，而且平均用时 ≤ 1.5 秒

拿到 1 星就能解锁下一关。

## 每日 10 分钟训练

点「开始今日训练」，App 会自动安排：

1. 🔁 **复习热身**（约 3 分钟）：优先出到期复习的音和薄弱的音。
2. 🐣 **认识新朋友**（约 2.5 分钟）：只有复习情况良好（到期复习的不超过 8 个，最近正确率 ≥ 80%）时才学新音，否则换成 💪 **弱项特训**。学新音时会先看一张介绍卡（谱上位置、琴键、唱名、记忆窍门、声音），然后集中练习。
3. ⚔️ **BOSS 战**，或者一个 🎮 **小游戏**（每天轮换）。

### 记忆调度（类似 Anki）

每个音（区分高音谱表和低音谱表）是一张卡，放在 0–6 号「记忆盒子」里：

- 答对，而且 3 秒内答出，才升一级。复习间隔依次是 1、1、2、4、7、15、30 天。
- 一天最多升一级，同一天反复答对只算练习。
- 答错降两级，当天要重练，第二天再考。
- 掌握度分五档：🥚 未学 → 🐣 刚认识 → 🐥 熟悉 → 🐦 熟练 → 🦅 精通。「精通」要求在 5 号盒以上，最近正确率 ≥ 90%，中位用时 ≤ 1.5 秒。

## 游戏厅

- ⚡ **60 秒快闪**：一分钟能认对多少个。
- 🚂 **音符小火车**：音符从右往左开过来，要在它到站前认出来，越认越快，有 3 条命。
- 🔤 **音符拼单词**：认出谱上一串音，拼出 BAG、FACE、CABBAGE 这样的英文单词。
- 🎯 **摆音符**：反向练习，听到声音、看到亮起的琴键，把音符摆到谱上。

## 家长看板

- 连续打卡天数、近 7 天练习时长
- 四级标准逐项达成情况
- 「掌握地图」：所有音按掌握度着色画在谱上
- 最需要加强的音
- 最常见的混淆，例如「低音谱表的 A3 → 认成了 C」，常常说明孩子没先看谱号
- 设置：答题方式、单行谱表或大谱表、简谱显示、键盘标记、每日时长、MIDI、备份和恢复

## 技术

纯 HTML/CSS/JS（ES 模块），无需构建，离线可用，数据只存在本机 localStorage。

```
note-quest/
  index.html, manifest.webmanifest, sw.js
  css/style.css
  js/music.js       乐理模型：位置、加线、唱名、简谱、键盘位置、地标提示（纯函数）
  js/curriculum.js  关卡、水平标准、单词库、成就
  js/srs.js         记忆盒子调度、出题权重、掌握度、水平评估、每日计划（纯函数）
  js/staff.js       五线谱 SVG 绘制
  js/glyphs.js      谱号字形（取自 Noto Music，SIL OFL 1.1）
  js/audio.js       Web Audio 钢琴音色、音效、MIDI
  js/store.js       本地存储
  js/app.js         界面与游戏
```

单元测试在仓库根目录的 `tests/note-quest.test.js`，用 `npm test` 运行。更新文件后，记得修改 `sw.js` 里的 `VERSION`，已安装的 App 才会更新。
